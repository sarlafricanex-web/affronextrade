Conclusion

Peut-on cloner et lancer ce repo ?

Oui, avec precautions

Le code source est propre et ne contient aucun pattern malveillant. C'est un serveur MCP standard qui sert de proxy vers l'API ScrapeGraphAI. Les risques identifies sont des problemes de hygiene, pas des menaces actives.

  1. Epingler les dependances : utiliser uv.lock (deja present) plutot que les versions plancher de pyproject.toml lors de l'installation.
  2. Ne pas definir SGAI_API_URL sauf si vous savez exactement ce que vous faites, car cette variable redirige votre cle API.
  3. Fournir la cle API via variable d'environnement, jamais en dur dans le code ou les fichiers de config.
  4. Utiliser dans un environnement isole (Docker ou venv) pour limiter l'impact en cas de probleme.
  5. Verifier les mises a jour regulierement, le repo est inactif depuis juillet 2026.
